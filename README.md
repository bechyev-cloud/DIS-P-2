# Дисциплина Pro

PWA-приложение для отслеживания привычек и тренировок. Работает офлайн (данные хранятся в localStorage на устройстве), устанавливается на телефон и компьютер как обычное приложение.

## Файлы

- `index.html` — само приложение (открывается напрямую в браузере для проверки)
- `manifest.json` — манифест PWA (иконка, название, цвет темы)
- `sw.js` — service worker для офлайн-режима и кэширования
- `icons/` — иконки приложения разных размеров

## Проверить локально

Просто откройте `index.html` в браузере — приложение полностью рабочее (данные сохраняются в localStorage). Service worker и установка как приложение требуют, чтобы сайт открывался по `https://` или `http://localhost` — из файла `file://` они не активируются, но сам трекер работает и так.

Для локальной проверки с сервером (Python уже есть почти везде):

```
python3 -m http.server 8080
```

и откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него все файлы из этой папки (сохраняя структуру, включая папку `icons/`).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` (или `master`) и папку `/ (root)`.
4. Сохраните — через минуту-две сайт появится по адресу вида `https://<ваш-логин>.github.io/<название-репозитория>/`.
5. Откройте эту ссылку на телефоне — браузер предложит «Добавить на главный экран», а на компьютере в адресной строке появится значок установки приложения.

## Синхронизация между устройствами

Локально приложение хранит все данные на устройстве (localStorage) — этого достаточно для полноценной работы офлайн. Встроенной серверной синхронизации между разными доменами (GitHub Pages) нет — при желании её можно добавить (например, через Firebase, Supabase или любой другой бэкенд), подключив вызовы к вашему API в функциях `pushRemote` / `initSync` внутри `index.html`.
